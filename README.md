Galaxy AI Enhancement — Samsung Galaxy M55 Family

A Magisk module that enables and enhances selected Galaxy AI and Samsung One UI features on the Samsung Galaxy M55 family.

📱 Supported Devices

* Samsung Galaxy M55
* Samsung Galaxy M55s
* Samsung Galaxy F55
* Samsung Galaxy C55

Compatibility may vary depending on firmware, One UI version, CSC, and device configuration.

✨ Features

* Galaxy AI feature enablement
* Samsung Gallery AI features
* AI-powered photo editing features
* Additional Samsung One UI feature flags
* Enhanced Samsung framework feature availability
* Selected flagship Galaxy features

⚙️ Requirements

* Magisk
* Root access
* Compatible Samsung Galaxy M55-family device
* Recommended: latest available Samsung One UI firmware

📦 Installation

1. Download the latest module ZIP from the Releases section.
2. Open Magisk.
3. Go to Modules.
4. Select Install from storage.
5. Select the downloaded ZIP.
6. Wait for installation to complete.
7. Reboot your device.

🗑️ Uninstallation

The module can be removed normally through:

Magisk → Modules → Galaxy AI Enhancement → Remove

Reboot after removing the module.

Use it at your own risk.
