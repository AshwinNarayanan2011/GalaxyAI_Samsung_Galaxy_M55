🤖✨ Galaxy AI Enhancement — Samsung Galaxy M55 Family

🚀 Bring more Galaxy AI & flagship One UI features to the Galaxy M55 family!

A Magisk module designed specifically for Samsung One UI 8.0 to enable and enhance selected Galaxy AI, One UI, Samsung Gallery, and flagship Galaxy features on supported Galaxy M55-family devices. 🧠📱✨

🎯 Target OS: One UI 8.0

This project is specifically made for One UI 8.0.
❌ One UI 7.x and older are not supported.
❌ One UI 8.5 and newer are not supported.

🐛⚠️ Known Bugs & Limitations

The module is still under development, so not every enabled feature is guaranteed to work perfectly. 😭🔧

🔴 AI Photo Editing Tools

Status: ❌ Not Working

The Galaxy AI photo editing tools that depend on Samsung Gallery’s AI/photo-editing framework currently do not function correctly.

You may see the feature or related UI, but attempting to use the AI editing functionality may fail or not produce the expected result.

🧪 This is currently being investigated.

📥🔥 Installation

1️⃣ Download

Download the latest Galaxy AI Enhancement ZIP from the Releases section.

2️⃣ Open Magisk

Open:

Magisk → Modules → Install from storage

3️⃣ Select the ZIP 📦

Select the downloaded Galaxy AI Enhancement module ZIP.

4️⃣ Flash the module ⚡

Wait for Magisk to finish installing the module.

5️⃣ Reboot 🔄

Reboot your device after installation.

6️⃣ Enjoy! 🤩

Once your phone boots, check the relevant Samsung apps and features.

Welcome to the Galaxy AI enhanced experience. 🧠✨📱

⸻

🗑️❌ Uninstallation

Removing the module is simple:

Magisk → Modules → Galaxy AI Enhancement → Remove

Then reboot your device. 🔄

If you experience a bootloop, use Magisk’s recovery/module-disable methods to disable or remove the module.
